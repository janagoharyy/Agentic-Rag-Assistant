# Agentic-Rag-Assistant
An agentic RAG assistant built with smolagents, combining local PDF retrieval and web search with an interactive Gradio interface. A hands-on project exploring AI agents and RAG.

## Overview

This project explores how AI agents can use tools to retrieve information from different sources and generate responses based on the results.

The assistant can:
- Search local PDF documents for relevant information.
- Use semantic search to retrieve relevant text chunks.
- Search the web for external information.
- Answer questions through an interactive Gradio chat interface.

## How It Works

The application uses two main information sources:

**1. Local document retrieval (RAG)**

PDF documents are processed into text, divided into overlapping chunks, and converted into embeddings using `nomic-embed-text` through Ollama. The embeddings are stored in ChromaDB, which retrieves relevant chunks when a user asks a question.

**2. Web search**

The agent can use a web search tool to find external information when a question requires information beyond the local documents.

**3. Agent and response generation**

A `ToolCallingAgent` from smolagents uses an LLM accessed through the Groq API to select tools and generate responses based on the available information.

**4. User interface**

Gradio provides a chat interface for interacting with the assistant.

## Tech Stack

- **Python**
- **smolagents** — agent and tool orchestration
- **Groq API** — LLM inference
- **Ollama (`nomic-embed-text`)** — text embeddings
- **ChromaDB** — vector storage and semantic retrieval
- **PyPDF** — PDF text extraction
- **Gradio** — chat interface
- **Requests** — communication with the local Ollama API


## Setup and Installation

### Prerequisites

- Python 3.12
- [Ollama](https://ollama.com/) installed
- A Groq API key
- Git

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd smolagents-agentic-rag-assistant
```

### 2. Create and activate a virtual environment

```bash
python -m venv .venv
```

On Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Ollama

Pull the embedding model:

```bash
ollama pull nomic-embed-text
```

Make sure the Ollama service is running before using local document retrieval.

### 5. Configure environment variables

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key
```

Replace the placeholder with your own API key. **Never commit your `.env` file or publish your API key.**

### 6. Add PDF documents

Place the PDF files you want to query inside the `documents/` directory.

### 7. Run the application

```bash
python app.py
```

Open the local URL displayed in the terminal to use the chat interface.

## Current Limitations

- Retrieval quality depends on the content and structure of the supplied PDF documents.
- PDF text extraction may not work well with scanned documents or image-only PDFs.
- Web-search results depend on the search provider and the queries generated by the agent.
- Response quality depends on the selected LLM and its tool-calling behavior.
- The application is an educational project and has not been designed or evaluated for production use.

## Learning Goals

This project was built to explore:

- The RAG pipeline: document processing, chunking, embeddings, and semantic retrieval.
